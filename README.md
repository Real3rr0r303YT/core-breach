## Was ist neu in v2.0.0

### 🔴 100-Level-Kampagne

Aus 5 Leveln werden **100**: zehn Welten mit je zehn Leveln, vom Bootloader bis tief ins Herz von OMNIGRID.

| Welt | Name | Welt | Name |
|:---:|---|:---:|---|
| 1 | BOOTLOADER | 6 | BROWSER |
| 2 | USERSPACE | 7 | CLOUD |
| 3 | FILESYSTEM | 8 | FIRMWARE |
| 4 | NETSTACK | 9 | MAINFRAME |
| 5 | KERNEL | 10 | OMNIGRID |

- **Steigender Schwierigkeitsgrad:** Mit jedem Level werden die Abschnitte länger, die Hindernisse kniffliger und die Daemons schneller.
- **Gleiche Level für alle:** Die Level werden mit festem Seed erzeugt. Jeder Spieler bekommt exakt dieselbe Kampagne, ideal zum Vergleichen.
- **Checkpoints** in langen Leveln und **Gravity-Reset-Felder** hinter Gravity-Passagen.
- **Neue Level-Auswahl:** eine Seite pro Welt, wischen zum Blättern, Boss-Level rot markiert.
- **Jedes Level ist schaffbar:** Alle 100 Level wurden automatisch in der Spiel-Physik durchgespielt, inklusive aller 3 Shards und aller Bosse.

### ☣ 10 Malware-Bosse

Jedes 10. Level ist eine Boss-Arena. Jeder Boss hat eine eigene Mechanik, und der Exit bleibt gesperrt, bis die Bedrohung neutralisiert ist.

| Level | Boss | Mechanik |
|:---:|---|---|
| 10 | **RANSOMWARE** | Ein Countdown läuft. Bei `00:00` sind deine Dateien verschlüsselt. Jeder Treffer kauft dir 8 Sekunden. |
| 20 | **TROJAN.DLL** | Tarnt sich als harmloser Data-Shard und schlägt zu, sobald du nah genug bist. |
| 30 | **SPYWARE** | Liest deine Eingaben mit, bewegt sich gespiegelt und klaut zeitweise dein HUD. |
| 40 | **WORM** | Repliziert sich laufend als neue Daemons ins Netz. |
| 50 | **ROOTKIT** | Unsichtbar und unverwundbar, bis ein Kernel-Scan oder ein Terminal-Hack es aufdeckt. |
| 60 | **ADWARE** | Pop-ups pflastern deinen Bildschirm zu. |
| 70 | **BOTNET.CNC** | Der Kontrollknoten schwebt unerreichbar, solange seine Bots leben. |
| 80 | **ZERO-DAY** | Zufällige Exploits: invertierte Steuerung, Speed-Surge, Teleport. |
| 90 | **APT.GHOST** | Advanced Persistent Threat: verfolgt dich, regeneriert sich und steht einmal wieder auf. |
| 100 | **OMNIGRID.EXE** | Der Endboss. Drei Phasen, die die Mechaniken der anderen Bosse kombinieren. |

> Bosse triffst du **von oben** auf die rot leuchtende Schwachstelle. Seitlicher Kontakt kostet Integrity.

## Gameplay

### Steuerung

| Aktion | Touch | Tastatur |
|---|---|---|
| Rollen | Dot-Ringe unten links | `A` `D` / `←` `→` |
| Springen | rechte Bildschirmhälfte | `Space` `W` `↑` |
| Kurzer Sprung | Finger früh loslassen | Taste früh loslassen |
| Welt wechseln (Auswahl) | wischen / Pfeile | `Q` `E` / `Bild↑` `Bild↓` |
| Zurück / Pause | `‖` oben rechts / Back | `Esc` |

### Spielelemente

| | Element | Verhalten |
|:---:|---|---|
| ● | **CORE-0** | Rollt per Drehmoment, 3 Integrity-Punkte |
| ■ | **Daemon** | Patrouilliert. Von der freien Seite treffen = Kill, seitlich = Schaden. Gibt's auch an der Decke. |
| ▲ | **Laser-Spikes** | Schaden + Respawn |
| ◆ | **Data-Shard** | 3 pro Level, für 100 % |
| ◎ | **Gravity-Switch** | Invertiert die Gravitation. Springen geht dann „nach unten“ |
| ┆ | **Gravity-Reset** | Setzt die Gravitation zurück auf normal |
| ▣ | **Terminal** | Öffnet die nächste Firewall rechts davon |
| ‖ | **Firewall** | Rote Laserwand, blockiert bis zum Terminal-Hack |
| ⚑ | **Checkpoint** | Nach einem Treffer startest du hier statt am Anfang |
| ▩ | **Boss** | Von oben auf die Schwachstelle treffen |
| ◇ | **Exit** | Level geschafft. In Boss-Arenen gesperrt, bis der Boss fällt |

## Selbst bauen

### Voraussetzungen

| Was | Version |
|---|---|
| JDK | 17 |
| Android SDK | Platform 35, Build-Tools 35 (nur für die APK) |
| Gradle | 8.10 (über den mitgelieferten Wrapper, nichts installieren) |

### Variante A: GitHub Actions (kein PC-Setup nötig)

Jeder Push auf `main` baut automatisch eine APK. Tab **Actions** → letzter Run `CORE//BREACH APK Builder` → **Artifacts** → `CORE-BREACH-apk`.

Release mit Download-Link für alle:

```bash
git tag v2.0.0
git push origin v2.0.0
```

→ Die APK hängt unter **Releases** als `CORE-BREACH-v2.0.0.apk`, der Versionsname kommt automatisch aus dem Tag.

### Variante B: Lokal mit Docker

Kein Android SDK nötig, alles läuft im Container:

```bash
./build.sh            # APK landet in dist/CORE-BREACH.apk
./build.sh install    # per adb aufs Handy
```

### Variante C: Lokal mit Android SDK

```bash
export ANDROID_HOME=$HOME/Android/Sdk
./build.sh native
# oder direkt mit Gradle:
./gradlew core:test android:assembleRelease
```

### Desktop: am PC spielen und testen

```bash
./build.sh desktop
# oder:
./gradlew desktop:run
```

### Tests

```bash
./gradlew core:test
```

Der Level-Validator prüft alle 100 Level: Spawn, 3 Shards, geschlossener Rand, befestigte Spikes, Boss alle 10 Level und eine deterministische Generierung. Er läuft in CI vor jedem Build. Ein kaputtes Level ergibt einen roten Build und keine APK.

<details>
<summary><b>Eigener Signier-Key für Releases</b></summary>

Ohne Key signiert der Workflow mit einem Debug-Key. Das funktioniert, aber dann erfordert jedes Update eine Neuinstallation.

```bash
keytool -genkeypair -v -keystore release.jks -alias corebreach \
  -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 release.jks > release.jks.b64
```

Repo → **Settings → Secrets and variables → Actions** → vier Secrets anlegen:

| Secret | Wert |
|---|---|
| `KEYSTORE_B64` | Inhalt von `release.jks.b64` |
| `KEYSTORE_PASS` | Keystore-Passwort |
| `KEY_ALIAS` | `corebreach` |
| `KEY_PASS` | Key-Passwort |

`release.jks` niemals committen (steht in `.gitignore`).

</details>

<details>
<summary><b>Eigene Level bauen</b></summary>

Level sind ASCII. 1 Zeichen = 1 Meter, die oberste Zeile ist die Decke.

```
#  Block        P  Spawn (1x)      X  Exit
D  Daemon       ^  Spikes          S  Shard (genau 3x)
G  Gravity      T  Terminal        F  Firewall
C  Checkpoint   B  Boss-Spawn      R  Gravity-Reset
.  leer
```

- Handgebaute Level: [`Levels.kt`](core/src/main/kotlin/dev/corebreach/level/Levels.kt)
- Kampagnen-Generator, Bausteine und Boss-Arenen: [`Campaign.kt`](core/src/main/kotlin/dev/corebreach/level/Campaign.kt)
- Boss-Logik aus kombinierbaren *Traits*: [`Boss.kt`](core/src/main/kotlin/dev/corebreach/world/Boss.kt)

Sprungphysik als Faustregel: **2 Blöcke hoch**, **bis 4 Blöcke weit**.

</details>

## Tech

| Layer | Stack |
|---|---|
| Sprache | Kotlin 2.0 (JVM 17) |
| Engine | libGDX 1.13 |
| Physik | Box2D, fester Zeitschritt 1/60 s |
| Rendering | 100 % `ShapeRenderer` + GLSL Post-FX (Glitch, Chromatic Aberration, Scanlines, Vignette) – null Bitmaps |
| Font | Prozedurale 5×7 Dot-Matrix |
| Audio | Prozedural generierte 8-bit-SFX |
| Build | Gradle 8.10 · AGP 8.7 · minSdk 26 · targetSdk 35 |
| CI | GitHub Actions → APK-Artifact + Release |

```

```
